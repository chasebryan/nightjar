# The GIF wardrobe

Every GIF the app plays lives in this folder — and nowhere else in
the project. One GIF per area, each under its slot's exact name:

| File           | Area                          |
| -------------- | ----------------------------- |
| `boot.gif`     | The boot ceremony             |
| `centipede.gif`| The Centipede release splash  |
| `eazy.gif`     | The EAZY ignition             |
| `magdump.gif`  | The Magdump ignition          |
| `redframe.gif` | The Redframe splash           |
| `assault.gif`  | The Net-Assault ignition      |

To give an area its GIF: upload the file into this folder with
exactly the slot's name (uploading the same name again replaces
the previous GIF), one at a time, and tell Skelli which area it
is for.

Any size and any aspect is fine — the app fits each GIF to the
screen it plays on: art whose shape mismatches the screen is
shown whole on black, matched art fills the screen. Phone,
tablet and laptop are all handled by the same fit law.
