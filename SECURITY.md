# Security policy

nightjar is a security tool, so its own security matters most of all.

## Reporting a vulnerability

**Do not file a public issue for a vulnerability.** A public post puts every
user at risk before a fix can ship.

Report it privately instead:

1. Go to this repository's **Security** tab.
2. Choose **Report a vulnerability** and describe it there.

That opens a private advisory visible only to the maintainer. Include:

- what the flaw lets an attacker do, in plain words;
- the version and device you saw it on;
- steps to reproduce, or a proof of concept;
- the impact as you judge it.

If the Security tab offers no report button, open a regular issue that says
only "I have a private security report — how do I reach you?" with **no
details of the flaw**, and a private channel will be arranged.

## Scope notes

- Findings about your own network made *with* nightjar are yours — they are
  not vulnerabilities in nightjar, and they don't need reporting.
- Crashes and ordinary bugs are not vulnerabilities; the bug-report form
  under **Issues** is the fastest road for those.
